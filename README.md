# Md Mahadi Hasan: Portfolio

Personal portfolio site built with React, Vite and Tailwind CSS, deployed to GitHub Pages.

**Live:** https://mahadi0007.github.io/Portfolio-website/

## Run locally

```bash
cd client
npm ci
npm run dev
```

Pushing to `main` deploys the site automatically.
